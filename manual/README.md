# マニュアル

- `案件管理システム_管理者ガイド.docx` … 所長・管理本部・経理・決済むけ。通知の見方と稟議の承認、設定の変えかた
- `案件管理システム_操作ガイド_担当者用.docx` … 営業担当・RD担当むけ。受注から求人掲載までの操作

## 作り直しかた

画面を変えたら、マニュアルの写真も撮り直します。

1. このフォルダの1つ上で簡易サーバーを立てる（例：`npx http-server . -p 5599 -c-1`）
2. `shots/` の画面写真を撮り直す（Chromeのヘッドレスで撮れます）
3. `node build-manual.js` で2冊とも作り直す

`build-manual.js` の `SHOTS` が写真の場所、`OUT` が出力先です。
文章を直すだけなら、Wordで直接編集してもかまいません。ただし次に作り直すと
上書きされるので、恒久的な修正は `build-manual.js` の側に入れてください。
