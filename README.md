# 案件管理システム（GitHub Pages + Supabase版）

受注 → 稟議 → 求人を一元管理するシステムです。案件の登録（①簡易求人・②稟議・③詳細）、原価率65%のゲート、
稟議の押印決裁、稟議書・ヒアリングシート・勤務説明書・簡易求人票の自動作成、Indeed・求人ボックスの求人数と実績の取込ができます。
データはSupabase（求人広告 運用ダッシュボードと同じプロジェクト）に保存されるため、**どの拠点のPC・スマホから開いても同じデータを共有**できます。

> **注意：ログイン機能はありません。** URL、またはこのリポジトリの `config.js`（Supabaseの接続先）を見た人は誰でも案件データを読み書きできます。
> 取引先の連絡先・請求単価・原価率が入るため、リンクは社内の非公開経路だけで共有してください。

## 0. 事前準備：Supabaseにテーブルを作る（初回のみ）

1. [Supabaseのダッシュボード](https://supabase.com/dashboard)にログインし、求人広告ダッシュボードと同じプロジェクトを開く
2. 左メニューの「SQL Editor」を開く
3. 同梱の `setup.sql` の中身をすべて貼り付けて実行（RUN）
4. 「Table Editor」に `anken_docs` というテーブルができていればOK

`jobs` テーブル（求人広告ダッシュボード）には影響しません。

### Claude版から今までのデータを移す（初回のみ・任意）

デスクトップの `anken-kanri_データ移行` フォルダにある `migrate_data.sql` を、同じく SQL Editor に貼り付けて実行します。
案件・掲載・取り込んだ求人広告・設定・応募シートの集計が入ります。何度実行しても同じ内容になります。
**このファイルは取引先の情報を含むため、GitHubにはアップロードしないでください**（`.gitignore` で除外しています）。

## 1. GitHub Pagesで公開する（初回のみ）

1. リポジトリの「Settings」→「Pages」
2. 「Source」を **Deploy from a branch** に設定
3. 「Branch」を `main`、フォルダを `/ (root)` にして **Save**
4. 1〜2分後に発行されるURL（`https://rdbusinessunit.github.io/anken-kanri/`）を社内に共有

`robots.txt` と `noindex` 指定で、検索エンジンには載らないようにしています。

## 2. 使い方の要点

- 画面右上の「入力者」で自分の名前を選んでから入力します（履歴と押印に使います）
- 他の人の変更は約20秒ごとに自動で反映されます（保存の直前にも最新を読み直します）
- 「求人管理」→「求人広告CSVを取り込む」で、Indeed（広告配信実績）と求人ボックス（採用ボードの求人一覧CSV＋求人別CSV）を取り込めます
- 「設定」→「バックアップ」で全データをJSONに保存できます。月1回程度の保存をおすすめします

Claude版にあったAI機能（求人診断・求人原稿作成・案件名の候補）は外しています。

## 3. 更新方法

ファイルを編集して `main` ブランチにpushすると、1〜2分でGitHub Pagesに反映されます。
画面が古いままのときは、ブラウザで再読み込み（Ctrl+F5）してください。

## 4. うまく動かないとき

### 画面上部に「Supabaseに接続できません」と出る

**無料プランのSupabaseは、一定期間アクセスがないと自動で一時停止**します。停止するとURLごと参照できなくなります。

1. [supabase.com/dashboard](https://supabase.com/dashboard) にログインしてプロジェクトを開く
2. 一時停止中なら再開ボタンを押す（日本語表示では **「履歴書プロジェクト」** と誤訳されています。*Resume project* のことです。隣の「Proにアップグレード」は有料なので押さない）
3. 数分待ってから画面の「再接続」を押す

データは一時停止中も保持されています。

### 「anken_docsテーブルが見つかりません」と出る

`setup.sql` がまだ実行されていません。「0. 事前準備」を行ってください。

### 「保存できませんでした」と出る

表示された理由を確認してください。401/403 は `config.js` のキーか `setup.sql` のポリシー、5xx はSupabase側の一時的な問題です。
保存に失敗した入力は画面に残っているので、原因を解消してからもう一度保存できます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面（見た目・読み込むファイル） |
| `config.js` | Supabaseの接続先 |
| `core.js` | データの保存・読み込み、計算、入力チェック |
| `caseview.js` | 案件一覧・案件画面（①②③・現場実態・履歴） |
| `docs.js` | 帳票（稟議書・ヒアリングシート・勤務説明書・簡易求人票）とExcel出力 |
| `postings.js` | 求人管理・設定・応募シート取込 |
| `ads.js` | Indeed・求人ボックスのCSV取込 |
| `main.js` | 画面の切り替えと操作 |
| `ref.js` | 職業安定業務統計の基準値・地域指数・業種リスト（稟議書テンプレートより） |
| `setup.sql` | Supabaseのテーブルとポリシー |
